# Detailing Studio

Адаптивный русскоязычный лендинг детейлинг-студии в Москве. Показывает услуги и цены, примеры работ, отзывы и контакты, помогает выбрать услугу и заполнить форму заявки.

## Возможности

- Каталог из 12 услуг с фильтрами «Кузов», «Защита», «Салон» и «Дополнительно». Выбор услуги в карточке переносит её в форму.
- Галерея из 9 работ с фильтрами, кнопкой «Показать ещё» и просмотром фотографий в диалоге. Переключение доступно с клавиатуры и свайпами.
- Непрерывная лента отзывов с паузой при наведении и отдельной кнопкой управления.
- Якорная навигация с подсветкой текущего раздела, мобильное меню и закреплённая мобильная кнопка перехода к форме.
- Форма с маской российского телефона, проверкой обязательных полей и согласия, состоянием успешного заполнения и повторным вводом.
- Анимации появления, световые лучи и частицы; поддержка `prefers-reduced-motion`, управление фокусом и ссылка перехода к основному содержимому.

**Форма работает в демонстрационном режиме:** данные проверяются только в браузере, не отправляются на сервер и не сохраняются в `localStorage`. После успешной проверки поля очищаются. Для приёма реальных заявок требуется подключить обработчик отправки.

## Стек

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4 и собственные стили. Для анимаций используются Motion и tsParticles, для диалогов — Radix UI, для иконок — Lucide. Изображения выводятся через `next/image`, шрифты Inter и Manrope подключены через `next/font/google`.

## Локальный запуск

Потребуются Node.js и npm, совместимые с зависимостями проекта.

```sh
npm ci
npm run dev
```

Откройте [localhost:3000](http://localhost:3000). Переменные окружения для текущей версии не требуются.

Для production-сборки и запуска:

```sh
npm run build
npm start
```

При сборке `next/font/google` загружает шрифты Google, поэтому необходим доступ к этому сервису.

## Проверки

```sh
npm run typecheck
npm run lint
npm test
```

Unit-тесты в `tests/unit/logic.test.ts` проверяют форматирование телефона, валидацию формы, сброс состояния и фильтрацию услуг.

Для браузерных тестов:

```sh
npx playwright install chromium firefox webkit
npm run build
npm run test:e2e
```

Playwright проверяет навигацию, форму, галерею, отзывы, мобильное меню, адаптивность и поведение при уменьшении анимации в Chromium, Firefox и WebKit. Конфигурация запускает сервер командой `npm run start` на порту 3000 либо использует уже работающий сервер по этому адресу.

`npm run format` форматирует исходники, тесты и конфигурационные файлы с помощью Prettier.

## Структура и редактирование

| Путь                            | Содержимое                                                                       |
| ------------------------------- | -------------------------------------------------------------------------------- |
| `src/app/page.tsx`              | Главная страница, преимущества, описание студии, этапы работы, контакты и подвал |
| `src/app/layout.tsx`            | Метаданные страницы, язык и шрифты                                               |
| `src/app/globals.css`           | Оформление, адаптивность и CSS-анимации                                          |
| `src/components/layout/`        | Шапка, меню и мобильная кнопка                                                   |
| `src/components/sections/`      | Каталог услуг, галерея, отзывы, форма и её контекст                              |
| `src/components/ui/`            | Кнопки, анимации появления и декоративные эффекты                                |
| `src/data/services.ts`          | Услуги, категории, цены и изображения карточек                                   |
| `src/data/company.ts`           | Контакты, время работы и показатели студии                                       |
| `src/data/portfolio.ts`         | Фотографии, подписи и категории работ                                            |
| `src/data/reviews.ts`           | Отзывы клиентов                                                                  |
| `src/data/navigation.ts`        | Пункты якорной навигации                                                         |
| `src/lib/lead.ts`               | Маска телефона, валидация и reducer формы, фильтрация услуг                      |
| `src/hooks/useActiveSection.ts` | Определение активного раздела навигации                                          |
| `public/images/`                | Локальные фотографии в формате WebP                                              |
| `tests/`                        | Unit- и E2E-тесты                                                                |

Источники фотографий и ссылка на лицензию Unsplash указаны в [`public/images/sources.json`](public/images/sources.json).
