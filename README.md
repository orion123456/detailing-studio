# Detailing Studio

Лендинг на Next.js, React и TypeScript.

```sh
npm install
npm run dev
```

Откройте http://localhost:3000. Для production: `npm run build`, затем `npm start`.

Проверки: `npm run typecheck`, `npm run lint`, `npm test`, `npm run test:e2e`.
Для первой установки браузеров: `npx playwright install chromium firefox webkit`.

Услуги и цены: `src/data/services.ts`. Контакты и показатели: `src/data/company.ts`.
Фотографии хранятся локально; источники и лицензия — `public/images/sources.json`.
